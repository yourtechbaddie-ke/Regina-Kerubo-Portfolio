# Visual Identity Rule — Portfolio Ecosystem

The main portfolio palette is a brand identity for the portfolio itself only. It must never be reused as the default visual system for standalone apps, campaign sites, dashboards, journals, labs, or future products.

## Rule
Every future app receives its own palette, typography pairing, image direction, surface treatment, and art direction. No future project should automatically inherit the portfolio's Black Cherry × Forest × Alabaster system.

Palette selection should be visually grounded in exceptional photographic references, especially Pexels photography, rather than generic web-app palettes.
