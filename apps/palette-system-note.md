# Palette System

Standalone projects must never inherit the portfolio palette by default. Each project gets an independent art direction based on its subject, audience and photographic references.

Approved current systems:
- The Private Letter: Midnight Cobalt / Porcelain / Champagne / Dusty Lilac
- The Regina Journal: Aubergine Noir / Plum Smoke / Dusty Rose / Shell / Smoked Gold
